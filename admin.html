Connexion administrateur

Cet espace vous permet d'ajouter, modifier et supprimer les photos et vidéos du site. Les fichiers sont enregistrés directement dans le dépôt GitHub — le site se met à jour automatiquement en 1 à 2 minutes.

Comment obtenir un jeton ?

📖 Suivez le tutoriel détaillé pas à pas (5 minutes, avec captures et pièges à éviter) — ou en résumé :

  1. Connectez-vous sur github.com → Settings → Fine-grained tokens
  2. Nom : « Admin site chorale » · Expiration : 1 an
  3. Repository access : Only select repositories → choisissez creme-anglaise-
  4. Permissions → Repository permissions → Contents : Read and write
  5. Cliquez « Generate token » et copiez-le ici.

⚠️ L'erreur « Resource not accessible by personal access token » signifie que le jeton n'a pas le droit d'écriture : vérifiez bien l'étape Contents : Read and write et que le dépôt creme-anglaise- est sélectionné. Si vous utilisez un jeton « classic », cochez la case repo entière.
